# Как помочь VARKENZA ROLEPLAY

Спасибо за интерес к проекту. Обсуждение, замечания и Pull Request приветствуются. Основной язык документации и общения — **русский**.

[Главная](README.md) · [План разработки](docs/ROADMAP.md) · [Список задач](https://github.com/Zeihos/VARKENZA-RolePlay/issues)

## С чего начать

1. Посмотрите [Issues](https://github.com/Zeihos/VARKENZA-RolePlay/issues): возможно, ваша проблема уже известна.
2. Для большого изменения сначала опишите идею в Issue — это помогает избежать дублирования.
3. Создайте свою ветку от `main`, например `fix/web-session` или `feature/game-inventory`.
4. Сделайте небольшие связанные изменения и добавьте тесты, если затронута логика.
5. Откройте Pull Request с описанием того, что изменилось и как это проверено.

## Как устроен проект

- `upstream/open.RP` — исходная база сторонних авторов; не редактируйте её содержимое в обход обновления подмодуля.
- `tools/` — скрипты для подготовки адаптированной копии open.RP.
- `game/` — отдельный Pawn-прототип, не смешивайте его со сборкой open.RP.
- `web/` — Node.js-прототип и тесты.
- `apps/` — локальные Python-приложения.
- `assets/` — оригинальные материалы оформления; не заменяйте их без необходимости.

## Проверка изменений

```bash
node --test web/tests/banking-core.test.js
python -m unittest discover -s tools/tests -v
node --check web/server.js
```

Для игровой части желательно приложить **реальный лог компиляции** и по возможности результаты запуска в игре. Проверка структуры файлов не равна компиляции мода.

## Правила оформления PR

- Название и описание пишите на русском; технические идентификаторы оставляйте как в коде.
- Объясняйте, **что сделано**, **зачем** и **как проверено**.
- Не выдавайте незавершённую функцию за работающую.
- Не включайте в PR `.env`, базы SQLite, пароли, токены, логи, временные файлы и скомпилированные артефакты.
- Не заменяйте сторонние лицензии или сведения об авторах без правовых оснований.
- Обновляйте документацию, если изменяется способ запуска.

**Важно:** исходники проекта доступны публично, но MIT-лицензия `open.RP` не означает автоматической лицензии на все прочие файлы VARKENZA.
