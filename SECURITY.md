# Безопасность проекта

VARKENZA ROLEPLAY находится в **технической альфе**. Веб-сервер и административные инструменты пока предназначены только для локального использования.

## Сообщения об уязвимостях

Не размещайте в публичных Issues действующие пароли, токены, содержимое пользовательских баз данных, секретные ключи и инструкции по эксплуатации уязвимости против реального сервера.

Если в GitHub доступна функция **Private vulnerability reporting**, используйте её для приватного сообщения. Если эта функция не включена, сначала свяжитесь с владельцем через его [профиль GitHub](https://github.com/Zeihos), не публикуя технические секреты в открытом Issue.

Обычные ошибки без угрозы безопасности можно сообщать через [шаблоны Issues](https://github.com/Zeihos/VARKENZA-RolePlay/issues/new/choose).

## Важные ограничения

- Веб-прототип должен работать только на `127.0.0.1`; не открывайте его напрямую в интернет.
- Используйте уникальные локальные значения секретов и не загружайте `web/.env` в Git.
- Не храните реальные учётные данные MySQL и RCON в файлах исходников.
- При работе с реальными пользователями нужны отдельные аудит, резервное копирование, HTTPS, ограничение доступа и журналы.
- SQLite-файлы удалены из текущего Git-дерева, **но могут оставаться в старой истории коммитов**. Если там были конфиденциальные данные, необходимы их проверка, ротация ключей и отдельное решение по очистке истории.

## Поддерживаемые версии

| Компонент | Поддержка |
| --- | --- |
| Техническая альфа в `main` | Только разработка и исправления |
| Предыдущие архивы/демо | Без гарантий безопасности |
| Публичная релизная версия | Пока не существует |
